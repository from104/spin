## 확정 사항 (전부 기현님 답변)

### 화면 배치
- **왼쪽 세로 스텝 바**(PPT 슬라이드 바) = 편집 전담: 목록·선택·복제·이동·사슬·삭제.
- **하단 TransportBar 는 재생 컨트롤만** 남기고 축소. 스텝 칩 줄은 폐기.
- 좁은(세로) 화면: 바가 **자동으로 접히고**, 버튼으로 열면 보드 위 **오버레이**.
  구현은 한 벌이다 — 좁은 화면 전용 UI 를 따로 두지 않는다.

### 스텝 카드
- **번호 + 썸네일만.** 스텝 이름은 UI 에서 폐기한다("스텝 정보 최소화").
  - `DrillStep.name` 필드는 당분간 모델에 남긴다. 기존 드릴에 이름이 있으면
    **노트 첫 줄로 합쳐 보존**(유실 없음) 후 비운다.
- 현재 스텝은 카드 강조로 표시. 카드 탭 = 그 스텝으로 이동.

### 복제 (후방 복제가 기본)
- 선택된 카드의 **복제 버튼**: 바로 아래로 복제.
- 스텝 사이 **틈(gap)에 호버/탭 시 + 버튼**: 그 자리에 **위 스텝의 복제**를 삽입.
  전방 복제도 이걸로 해결된다. 맨 앞 틈의 + 는 아래(첫) 스텝을 복제.

### 사슬 (스텝 간 연결 토글)
- 틈에 **사슬 버튼 토글**. **기본 연결.**
- 재생·시연에서: 연결 = 지금처럼 보간 애니메이션, **끊김 = 그 경계만 즉시 컷**
  (멈추지 않고 순간 점프, 재생은 계속 흐른다).
- 저장은 **예외만** 싣는다: 끊긴 경계의 **다음 스텝**에 `cut: true`. 키가 없으면 연결.
  옛 드릴은 키가 없으므로 자동으로 전부-연결 = **지금 시연 동작 그대로, 마이그레이션
  불필요.** ("없음 = 참" 이 증명되는 경우다 — SUMMARY 교리와 같은 논법.)

### 다중 선택
- **선택 모드 토글 버튼**(바 상단) → 카드에 체크박스. 오조작 없는 명시적 모드.
- 이동: 체크된 카드 아무거나 **드래그**하면 묶음이 함께 이동, 놓을 틈이 하이라이트.
- 일괄 복제·삭제 버튼은 선택 모드 중 바 상단에.

### 텍스트의 소속 (조사 교집합 ③)
- **스텝 노트**: 보드 아래 **접이식 패널**(PPT 발표자 노트 자리). 선택 스텝의
  `DrillStep.note`(이미 모델에 있음, ≤600자). 지금은 평문, 추후 md 렌더.
- **드릴 짧은 설명**: 편집 화면 **헤더 인라인**(제목 옆/밑 한 줄, 클릭 편집).
  `Drill.description`(이미 모델에 있음). 목록 카드에 부제로 표시.

## 모델 변경 요약

| 변경 | 방식 | 마이그레이션 |
|---|---|---|
| `DrillStep.cut?: true` | 새 optional 필드, 없으면 연결 | 불필요 (없음 = 참) |
| `DrillStep.name` | 필드 유지, UI 폐기 | 로드 시 note 로 병합 |
| 목록 카드 부제 | `DrillSummary` 에 description 실림 | **SUMMARY_BUILD 3** — 옛 요약엔 키가 없으므로 범프 필요. 재구축 경로(세션 1회)는 이미 있으니 범프가 싸졌다 |

## 구현 순서 (커밋 단위)

1. **모델+재생**: `cut` 필드 · sampleDrill 이 끊긴 경계에서 보간 대신 컷 · 시연 반영.
2. **StepSidebar**: 목록·현재 스텝·탭 이동 + TransportBar 를 재생 전담으로 축소.
   접이식/오버레이 반응형 포함.
3. **복제**: 카드 버튼 + 틈 + 버튼.
4. **사슬 토글 UI**: 틈의 사슬 버튼, 상태 표시.
5. **선택 모드**: 체크박스·드래그 이동·일괄 복제/삭제.
6. **텍스트**: 노트 접이식 패널 · 드릴 설명 헤더 인라인 · 목록 부제(SUMMARY_BUILD 3).
7. **이름 이관**: name → note 병합 정화기.

각 단계가 독립적으로 배포 가능한 상태를 유지한다(1이 끝나면 사슬 없는 UI 라도 재생은
그대로, 2가 끝나면 복제 없이도 기존 흐름 유지).
