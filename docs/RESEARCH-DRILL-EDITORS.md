# 유사 앱 조사 — 드릴 편집 제로베이스 재설계의 입력 (2026-08-17)

기현님 지시: *"드릴 편집을 전면적으로 (정말 제로베이스에서) 다시 설계하자. 유사 앱 자료 조사 집중해서 2케이스만 조사"*.

케이스 선정 기준: SPIN 과 **구조가 겹치는 정도**다.

- **케이스 1 — FastDraw (FastModel Sports)**: 농구 작전판·플레이북의 업계 표준(15년+).
  파워체어 풋볼과 **같은 농구 코트**, SPIN 과 같은 **프레임(스텝) 단위 스냅샷** 모델.
  1차 자료: 공식 데스크톱 사용자 가이드 PDF 52쪽 전문.
- **케이스 2 — Sportplan (Drill Designer + Animator)**: 웹 기반 멀티스포츠 드릴 편집기.
  SPIN 과 같은 **브라우저 환경**이고, 드릴→세션(연습 계획) 계층이 SPIN 의 목록·시연과 겹친다.
  1차 자료: 공식 도구 FAQ·제품 페이지.

## 케이스 1 — FastDraw

### 구조: 라이브러리와 편집기가 한 화면이다

Draw 탭 하나가 **좌 Play Library + 우 Play Editor** 로 나뉘고, 분할선을 드래그해 비율을
바꾼다. 목록과 편집이 화면 전환 없이 공존한다 — 옆 드릴을 참조하면서 그린다는 뜻이다.
보기 모드는 Draw / Playbook / Preview 세 탭뿐이다.

### 새 플레이 생성 = 메타데이터를 먼저 받는다

New Play 메뉴에서 이름 + **Season / Team / Series** 라벨(콤보에서 고르거나 즉석 추가)과
코트 설정(하프/풀, **Include Out of Bounds** 체크)을 받고 나서야 편집기로 들어간다.
가이드가 명시한 베스트 프랙티스: 아웃오브바운즈를 안 쓰면 끄라 — **안 쓰는 영역이
다이어그램 크기를 깎아먹는다**.

### 개체 추가: 한 번에 다섯, 공 소유자까지

- **FastAdd**: 버튼 하나로 선수 1~5 를 프레임에 넣고 **볼핸들러를 지정**한다
  ("Player 1 Ball" = 5명 배치 + 1번에게 공). 개별 드래그 배치가 아니라 **대형(formation)
  단위 투입**이 기본 동선이다.
- 선수 번호는 더블클릭으로 커스텀 라벨로 바꾸고, 커스텀 라벨 세트를 저장해 두면
  FastAdd 가 그 라벨로 넣는다.
- **FastDefense**: 공격수가 이미 있으면 우클릭 한 번으로 **대응 수비수 5명을 자동 추가**
  (원형/텍스트 스텐실 선택).

### 액션: 이동선이 곧 의미다

Actions 팔레트에서 스텐실을 끌어다 놓으면 **Screen / Cut / Dribble / Pass 중 무엇인지
묻는 메뉴**가 뜬다. 선은 장식이 아니라 **타입이 있는 액션**이다. 놓인 선은 양 끝
**초록 점**(끝점 이동)과 곡선의 **노란 중간 원**(호 조절)으로 편집한다 — SPIN 의 화살표
굽힘 앵커와 동일한 문법.

### FastBuild: 액션이 다음 프레임을 만든다 ★ 이 앱의 심장

프레임 1 에 액션(컷·패스…)을 그린 뒤 FastBuild 버튼을 누르면 **선수는 자기 컷/스크린의
종점으로, 공은 패스 선을 따라 받은 선수에게로 이동한 상태의 다음 프레임이 자동 생성**된다.
"매 프레임 선수를 다시 놓을 필요가 없다"가 공식 문구다. 액션 타입을 받는 이유가 여기서
드러난다 — **타입이 있어야 다음 프레임을 계산할 수 있다**.

### 프레임별 텍스트는 두 층이다

- **Frame Description**: 프레임 바로 아래를 더블클릭해 쓰는 짧은 설명. 인쇄 시 기본으로
  각 프레임 밑에 그대로 나온다.
- **Coaching Points**: 프레임이 아니라 **플레이 전체**에 붙는 긴 노트. 기본은 숨겨진
  서랍(편집기 하단 화살표로 펼침)이고, **포지션별(Pos) 칸 + 일반 설명 칸**으로 나뉜다.
  인쇄 기본값에는 **안** 들어간다(설정으로 켬).

짧은 설명은 프레임에, 원리·읽기는 플레이에 — **텍스트의 소속이 두 단계로 분리**돼 있다.

### Building Blocks: 대형·상용구를 템플릿으로

자주 쓰는 대형/공통 액션을 Building Block 타입으로 저장해 두면, 아무 플레이의 아무
프레임에나 팔레트에서 꽂아 넣는다. Series 라벨로 하위 폴더가 잡히고, 플레이↔블록 상호
변환도 된다(일괄 선택 → Convert to Plays).

### 그 외 편집 문법

- 우클릭 메뉴가 **어디를 눌렀느냐에 따라 3종**(개체 / 프레임 / 라이브러리)으로 갈린다.
  삭제·Clear Frame·FastDefense 등 다수 기능이 여기에 산다.
- **FastColor**: 개체 선택 → 색 아이콘 → 최근 색 재사용.
- 라이브러리는 Season/Team/Series/이름으로 정렬·다중 선택 일괄 라벨 변경.
- 인쇄가 1급 시민이다: 페이지당 프레임 배치(Frame Layout), 목차 자동 생성, 코트 배경
  포함 여부까지 플레이북 설정으로 제어.

## 케이스 2 — Sportplan

### 구조: 만들기(도구)와 쓰기(세션)가 분리된 계층

**Chalkboard(Drill Designer)** 로 정적 스케치를, **Animator** 로 동적 드릴을 만들고,
결과물은 전부 "내 스케치" 폴더로 들어간다. 스케치/애니메이션에 **노트와 코칭 포인트**를
붙이고, 그것을 **Session(연습 계획)** 에 꽂아 인쇄·PDF·공유한다. 드릴은 재료고 세션이
완성품이다.

### Chalkboard: 드래그&드롭 스케치

- 종목별 피치/코트 템플릿 다수 + **사용자 사진 업로드 배경**도 허용.
- 아이콘(선수·공·콘)·화살표·텍스트를 끌어다 놓는 단순 문법. **자동 저장**.
- 목적을 명시한다: "말로 설명하는 대신 그림으로 절반의 시간에" — 정밀함보다 속도.

### Animator: 타임라인이 없는 애니메이션 ★ 이 앱의 심장

공식 문구: *"There are no timelines here. Simply draw it how you would describe it."*

- 개체를 놓고 → **선수를 클릭해 이동선을 긋는다**. 공을 가진 선수에게 선을 그으면
  **pass / shoot 등 추가 옵션**이 뜬다 — FastDraw 와 똑같이 선에 타입이 붙는다.
- **액션 기반 연쇄**: 각 액션은 앞 액션·다른 선수의 액션·공의 이동에 **의존**해서
  순서대로 발화한다. 코치는 순서를 키프레임으로 편성하지 않고 **의존 관계로 서술**한다.
- 이동·패스 **속도는 가변**, 패스 종류는 **색으로 구분**. 재생/일시정지가 편집 중에도
  가능하고 **재생 후에도 계속 그릴 수 있다**(편집↔재생이 모드 전환이 아니다).
- 완성물은 업로드해 스케치 폴더로 → 노트·코칭 포인트 → 세션 편입 → 공유.

### 세션 플래너에서 배운 것

- 탐색 중 마음에 든 드릴을 **클립보드에 담아 두고**(순서 재배열 가능) Quick Save 하면
  그대로 세션이 된다 — 수집이 곧 초안.
- 세션 안에서 드릴 삽입 시 **그 드릴의 노트를 함께 복사할지** 선택.
- 세션은 섹션(행) 단위로 구성, 이미지 크기 % 조절, 인쇄·PDF·공유 버튼.

## SPIN 재설계에 시사하는 것 (두 케이스의 교집합부터)

두 앱이 **독립적으로 같은 결론**에 도달한 지점이 셋 있다. 교집합은 우연이 아니다.

1. **선에는 타입이 있다.** 패스인지 드리블인지 컷인지를 앱이 안다. 그래서 FastBuild
   (다음 프레임 자동 생성)와 Sportplan 의 의존 연쇄 애니메이션이 **가능해진다**.
   SPIN 의 화살표는 현재 색·굽힘만 있는 무명(無名) 선이다 — 타입 없는 선 위에는
   어떤 자동화도 지을 수 없다.
2. **다음 스텝은 손으로 다시 놓는 게 아니라 액션에서 계산된다.** FastBuild 가 이 앱의
   구매 이유 1순위로 꼽히는 기능이다. SPIN 은 스텝 복제 후 전부 손 이동이다.
3. **텍스트는 소속이 있다.** 프레임(스텝)의 짧은 설명 vs 드릴 전체의 코칭 포인트
   (포지션별 포함). SPIN 의 메모는 코트 위 쪽지 하나뿐이라 이 구분이 없다.

교집합 밖에서 각자 가져올 것:

- FastDraw 에서: **대형 단위 투입**(FastAdd/FastDefense — SPIN 이라면 "4+GK 홈 대형",
  "상대 4명 자동") · **Building Blocks**(씨앗 드릴과 결이 같다 — 드릴이 아니라 **부품**을
  저장) · 문맥별 우클릭 3종 · 인쇄 1급 시민.
- Sportplan 에서: **타임라인 없는 재생**(스텝 스냅샷을 유지하면서 스텝 사이를 액션
  의존 순서로 보간하면, 코치는 여전히 "그리듯" 만들고 시연은 살아 움직인다) ·
  편집 중 재생(모드 전환 없음) · 드릴→세션 계층(ROADMAP 의 연습 계획과 연결).

⚠️ 반면교사도 하나씩: FastDraw 는 데스크톱 시대 UI(우클릭 의존)가 그대로 남아 iPad 앱
평점이 2.7 이다 — **포인터 하나로 다 되는 문법**이 먼저고 우클릭은 지름길이어야 한다.
Sportplan 은 Animator 가 별도 다운로드 도구였던 역사 탓에 만들기/쓰기 동선이 끊긴다 —
SPIN 은 한 화면에서 끝나야 한다.
