# 파워체어 풋볼 — 배경 자료 모음

규칙(Laws) 밖의 것들을 모아 둔다: **역사 · 국제 통합 과정 · 미국 현황 · 종목의 의의 · 선수 분류**.
2026-08-31 수집(기현님 지시: *"자료 더 검색해 역사나 의의, 특히 미국쪽 자료"*).

## 왜 여기에 따로 두나

`docs/RULES-FIPFA-2025.md` 는 **Laws 1~18 요약 전용 정본**이고 *"이 문서를 고치지 않고 앱 텍스트만
고치는 것은 금지"* 라는 규율이 걸려 있다. 역사·의의는 그 문서의 범위가 아니므로 섞지 않는다.
규칙 화면의 **[소개] 카드**가 참조할 출처는 이 디렉터리다.

## 한눈에 — 연표

| 시기 | 일 |
|---|---|
| 1970년대 | 프랑스 교사들이 고안. 낡은 농구공 + 코트 가장자리 나무판 |
| 1978 | 프랑스 "전동휠체어 축구" 정착. 3부 리그 30팀 + 전국선수권까지 발전 |
| 1979~80 | 캐나다가 **독립적으로** "Power Soccer" 고안 → 일본·미국으로 (일본어 위키는 미국·캐나다 1980) |
| **1982** | 🇯🇵 **오사카시 신체장애인스포츠센터**에서 북미 파워사커를 힌트로 시작. 일본 첫 팀 **오사카 롤링터틀** |
| 1983 | 브리티시컬럼비아 장애인체육대회에서 인정 |
| **1988** | 🇺🇸 **BORP(버클리)가 미국에 도입** — 클리닉으로 산호세·홀리스터·샌디에이고 확산 |
| **1989** | 🇫🇷 장애인 종합대회 *Jeux de l'Avenir* 에서 **공개 종목** |
| **1991** | 🇫🇷 같은 대회에서 **첫 공식 종목** |
| **1992** | 🇫🇷 **프랑스 국내선수권** 시작 / 🇺🇸 Eric Dornan 이 샌디에이고 팀 합류, Jerry Frick 을 만남 |
| **1995** | 🇯🇵 **JPFA 발족** — 일본선수권·대표팀 파견 시작 |
| 2004 | 미국 코치 David Ruelas 가 벨기에에서 유럽식을 발견, 프랑스 디렉터 Herve Delattre 와 접촉 |
| **2005** | 🏴󠁧󠁢󠁥󠁮󠁧󠁿 **WFA 설립** — 잉글랜드축구협회(FA) 공인 |
| 2005-01 | 7개국 24명, 프랑스 르셰네 — **IPFA** 기초. 4개 변종 통합이 최우선 과제 |
| 2005-10 | 포르투갈 코임브라 — **영국 규칙을 국제 표준으로 만장일치 채택** |
| 2006-07 | 미국 애틀랜타 — 규칙 확정, **FIPFA 로 개명**(본부 파리). 미국축구협회 심판 Chris Mulholland 가 국제 경기규칙 개발 주도 |
| 2006-08/10 | **USPSA 창립**(본부 인디애나 카멜) |
| 2007-02 | USPSA 비영리(501(c)(3)) 지위 |
| 2007-10 | **제1회 월드컵 도쿄 — 미국 우승** |
| 2008-02-19 | USPSA, 미국축구협회(USSF) 준회원 |
| 2011-11 | **제2회 월드컵 파리 — 미국 우승**(축구 종목 최초 미국 연패) |
| 2013 | 🇦🇺 호주가 제1회 **APO(아시아·태평양·오세아니아) 컵** 개최 |
| 2014-07 | 🇫🇷 제1회 EPFA Nations Cup(아일랜드 리머릭) — **프랑스 우승** |
| 2017-07 | 제3회 월드컵 플로리다 키시미 — **프랑스 우승**, 미국 준우승, 일본 5위 |
| 2019 | 🏴󠁧󠁢󠁥󠁮󠁧󠁿 EPFA Nations Cup(핀란드) — **잉글랜드 우승**, 유럽 챔피언 / 🇦🇺 제2회 APO 컵 |
| 2022 | 🇺🇸 **US Soccer 가 Team USA 를 Extended National Team 으로 출범** |
| 2023-10 | 제4회 월드컵 **시드니**(10개국, 첫 라운드로빈) — **프랑스 2연패**, 잉글랜드 준우승, **미국 3위**, 호주 6위 |
| 2025 | 🇫🇷 EPFA 유럽선수권(이탈리아) — 프랑스 우승 / 🇦🇺 제3회 APO 컵(브리즈번) |

## 앱에 쓸 때의 규율

- 수치·날짜는 이 디렉터리의 파일에서 **그대로** 인용한다. 반올림·의역하지 않는다.
- 출처가 갈리는 사실은 **양쪽을 병기**한다(예: USPSA 창립 시점 — 공식 사이트 "8월 선거 / 10월 공식
  설립" vs Wikipedia "7월 공식 설립").
- 앱 텍스트만 고치고 이 문서를 안 고치는 것은 금지 — `RULES-FIPFA-2025.md` 와 같은 규율이다.
